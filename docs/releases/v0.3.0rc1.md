# printguard 0.3.0rc1 (pre-release)

**Not homologated.** No record of a run on a physical printer has been committed, so this is a release candidate. A stable 0.3.0 will follow only after a filled-in checklist passes `scripts/check_homologation.py` (see [releasing.md](../releasing.md)).

What it adds over 0.2.1:

- `printguard --version`, `resolve --day`, and an alert for any earlier day left unresolved.
- Exit code 5 for an unexpected error, with an alert and the lock released.
- Event Log alerts through `Write-EventLog` and a `printguard` source registered by the installer.
- Alerts are de-duplicated against the whole day's file.
- On POSIX the working directories are created private to their owner.
- Package metadata uses an SPDX license expression.
- [Installation procedure](../installation-windows.md), [homologation checklist](../homologation-checklist.md) and a [checklist verifier](../releasing.md).

Verified: 88 tests locally on Linux, 8 more against a real paused print queue on a hosted Windows runner, CI green on Ubuntu and Windows with Python 3.11 and 3.12.

Known limitations are the same as 0.2.1, plus the open question of the physical printer: see [windows-validation.md](../windows-validation.md) for what has and hasn't been checked.
